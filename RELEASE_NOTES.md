# Hold to Dictate 0.1.0

Первый выпуск для macOS 13 и новее. Архив универсальный для Apple Silicon и Intel.

- Глобальное удержание ⌘⇧K с переназначением в настройках.
- Нативный оверлей с индикатором голоса и предварительным текстом.
- Копирование и автовставка после отпускания.
- Диктовка через сессию Codex и дополнительный локальный режим Apple Speech.
- Превью, автозапуск и настройки внешнего вида.

Для первого запуска откройте приложение и выдайте разрешения через меню со значком волны. Подробности по запуску, режимам и локальной подписи — в README.
